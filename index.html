replworks 오픈소스 프로젝트의 최신 패키지를 Debian 및 Ubuntu 시스템에서 apt로 바로 설치할 수 있도록 제공하는 공식 저장소입니다.

Distribution: stable Architectures: amd64, arm64 GPG Signed: replworks.gpg

저장소 요약

  • Suite: stable
  • Component: main
  • GPG Key: /replworks.gpg
  • Metadata: /dists/stable/InRelease

⚡ 저장소 등록 및 설치 방법

터미널에서 아래 명령어를 실행하여 GPG 키와 저장소 소스 목록을 등록하세요.

RECOMMENDED 원라이너(One-liner) 자동 설정 
sudo mkdir -p /etc/apt/keyrings && curl -fsSL https://apt.repl.net/replworks.gpg | sudo tee /etc/apt/keyrings/replworks.gpg >/dev/null && echo "deb [signed-by=/etc/apt/keyrings/replworks.gpg] https://apt.repl.net stable main" | sudo tee /etc/apt/sources.list.d/replworks.list && sudo apt update

* GPG 키 다운로드, APT 소스 리스트 생성, 패키지 목록 업데이트까지 한 번에 완료됩니다.

또는 단계별로 직접 실행하기

1 GPG 서명 키 저장소 등록 
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://apt.repl.net/replworks.gpg | sudo tee /etc/apt/keyrings/replworks.gpg >/dev/null
2 APT 저장소 리스트 추가 
echo "deb [signed-by=/etc/apt/keyrings/replworks.gpg] https://apt.repl.net stable main" | sudo tee /etc/apt/sources.list.d/replworks.list
3 패키지 목록 업데이트 및 패키지 설치 
sudo apt update && sudo apt install <패키지 이름>
